# AZ-104 hands-on projects

Scenario-based labs for people studying for the Microsoft **AZ-104 (Azure Administrator)** exam. Each project is a small, realistic business problem you build in the Azure portal first (to learn the "why"), then can redeploy from Bicep.

> Unofficial study material. Not affiliated with or endorsed by Microsoft. Contains no Microsoft Learn text or exam content.

| Project | Scenario | Status |
|---|---|---|
| [5 - Secure client data](project-5-secure-client-data/) | Accounting firm: isolated, private, auditable client storage | Ready |
| 3 - Three-tier ERP | Law firm: web/app/db tiers, NSGs, load balancers, Azure Files, backup | Coming |
